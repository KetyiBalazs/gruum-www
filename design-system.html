Design system

Live tokens from getgruum.com

The marketing site is a quiet paper page with one lime wash, hairline dashed rails, and a 160px left sidebar. Color is rationed. Type never goes below 10px.

Minimum type size: 10px. Labels, badges, captions, and code clamp to this floor.
